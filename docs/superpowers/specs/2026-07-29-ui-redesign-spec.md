## 0. 摘要

对 LiveTranslate 前端进行完全重设计。产品从"工程师调试工具"转型为**消费级翻译产品**：它既是客户未来终端产品的"样板间"，也是可直接面向终端用户使用的完整应用。设计方向为"温暖高效型"（Notion / Things 3 / Craft 气质），浅色默认 + 深色可切换，Tailwind CSS + shadcn/ui 实现，暖橙/琥珀主色，系统字体栈。

**⚠️ 产品结构变更（非纯视觉调整）**：原设计文档中的"单人测试模式"（§5.1）与"实时翻译机模式"（§5.3）合并为统一入口"实时翻译"，内部通过 Tab 切换"文本模式/耳机模式"。此变更影响原文档的模式划分、路由结构与开发计划，需同步修订产品设计与需求文档。

## 1. 设计决策总表

| # | 决策项 | 结论 | 理由 |
|---|--------|------|------|
| 1 | 视觉定位 | 消费级产品感，非开发者工具 | 产品是客户终端产品的样品，也面向终端用户 |
| 2 | 美学方向 | 温暖高效型（Notion/Things 3/Craft） | 留白、排版层级、柔和圆角传达品质，避免 AI 产品刻板印象 |
| 3 | 主题策略 | 浅色默认 + 深色可切换；播放/字幕沉浸场景自动深色 | 消费级用户期待双主题；字幕场景深色是功能需求 |
| 4 | 技术实现 | Tailwind CSS + shadcn/ui | 无头组件保证行为一致性，视觉完全自主控制；客户参考价值高 |
| 5 | 导航结构 | 侧边栏 3+2 分层：实时翻译/文件配音/会议 + 历史/设置 | 按用户心智组织；合并同类模式降低认知门槛 |
| 6 | 品牌与主色 | 产品名 LiveTranslate；暖橙/琥珀色系 | 翻译 = 人际沟通，暖色传达人文感 |
| 7 | 字体 | 系统字体栈，不引入自定义字体 | 中文 webfont 体积大、字重不全；品质靠排版规则建立 |
| 8 | 译文呈现 | 精致卡片流：默认只显示译文，原文折叠，操作 hover 浮现 | 卡片是天然操作单元（回放/状态），降噪后接近连续流的干净 |
| 9 | 动效策略 | "呼吸感"：稳态静止，动效仅服务于内容诞生与状态迁移 | Things 3/Craft 哲学：安静但有生命感 |
| 10 | 全屏字幕 | 舞台演讲式：居中字幕 + 半透明常驻控制条 + 音频呼吸光晕 | 实时工作场景需要状态可见 + 一键操作 |
| 11 | 配音工作台 | 渐进分层：默认只有播放器+字幕流+主操作，复杂度按需浮现 | 简单路径零门槛，专业功能不删除只收纳 |
| 12 | 会议模式 | 圆桌式：头像环 + 热座呼吸高亮 + 首字色块头像 | 空间隐喻 = 参与感；高亮识别速度快于文字标签 |
| 13 | 首次体验 | 三步引导：欢迎→连接（Key+自检）→就绪 | Key 是先决条件前置；非必要配置全部后置 |
| 14 | 指标展示 | 性能徽章：运行时 1-2 个关键数字，会话结束生成摘要卡 | 普通用户感受品质，技术客户看到量化证据 |
| 15 | 历史页 | 时间轴 + 摘要卡片流，按日分组，点击展开，轻量筛选 | "翻译资产库"的安全感，非数据库查询界面 |
| 16 | 设置页 | 四组分区卡片；热词表双入口（设置页管理+翻译页快选） | 按使用频率分层；高频功能不给用户跑腿 |
| 17 | 错误状态 | 安静恢复为主 + 原地引导卡片；文案指向"下一步做什么" | 技术细节折叠可复制，不打断流程 |
| 18 | 窗口弹性 | 基准 1280px，弹性 1024–1920，最小 960×640 | 侧边栏 <1100px 收缩为图标栏；内容区限宽 860px |
| 19 | 交付物 | 设计规范文档 + Canvas 高保真交互原型 | 文档指导开发，原型供客户直接感知 |

## 2. 设计原则

1. **内容即界面**：译文是产品 80% 的屏幕时间，一切布局为阅读服务——限宽、大字号、高行高、明确分段。
2. **安静优先**：稳态时界面完全静止；色彩用于状态而非装饰；动效只出现在内容诞生和状态迁移时刻。
3. **渐进浮现**：默认视图只展示当前任务的核心操作，高级功能 hover/展开/折叠触达，不删除只收纳。
4. **错误即引导**：每个错误状态都告诉用户下一步做什么；技术细节永远在二级位置可复制。
5. **双受众兼容**：普通用户看到体感（"响应很快"），技术客户看到数据（"首字延迟 929ms"）——同一界面，两层信息。

### 3.2 字体与排版

```
--font-sans: -apple-system, 'Segoe UI', 'PingFang SC', 'Microsoft YaHei', 'Noto Sans SC', sans-serif;
--font-mono: 'SF Mono', 'Cascadia Code', 'Consolas', monospace;
```

| 层级 | 字号 | 行高 | 字重 | 用途 |
|------|------|------|------|------|
| Display | 40px | 1.4 | 600 | 全屏字幕译文 |
| H1 | 24px | 1.4 | 600 | 页面标题 |
| H2 | 17px | 1.5 | 600 | 卡片标题、区块标题 |
| Body-L | 17px | 1.75 | 400 | 译文正文（核心阅读层） |
| Body | 14px | 1.7 | 400 | 通用正文 |
| Caption | 13px | 1.6 | 400 | 原文、辅助信息 |
| Micro | 11px | 1.5 | 500 | 时间戳、badge、标签 |

规则：
- 中文正文行高 ≥ 1.7（阅读舒适度）
- stash 预测文本：60% 不透明度 + 正常字重（禁止斜体，中文斜体视觉效果差）
- 内容区最大阅读宽度 860px，居中
- 数字使用 `font-variant-numeric: tabular-nums`

## 5. 页面设计规格

### 5.1 Onboarding（首次引导）

**触发条件**：本地无有效 Key 配置时，任何路由重定向到 `/onboarding`。

**Step 1 — 欢迎屏**
- 居中布局，最大宽度 560px
- LiveTranslate logo mark（48px）+ 产品名（H1）
- 一句话定位："实时同声传译，三种方式使用"
- 三大模式卡片横排：各含图标 + 模式名 + 一行描述
  - 实时翻译："对着麦克风说话，即刻看到/听到译文"
  - 文件配音："导入音视频，自动生成多语言配音"
  - 会议翻译："多人轮流发言，以发言人音色播放译文"
- 底部主按钮"开始设置"

**Step 2 — 连接屏**
- API Key 输入框（password 类型 + 显示切换）
- Workspace Host 输入框（预填 `https://dashscope.aliyuncs.com` 格式的默认值）
- "测试连接"按钮 → 加载态 → 成功：绿色对勾动效 + "连接成功 · 延迟 {n}ms"；失败：原地错误卡片（原因 + 修复建议 + "在哪里获取 Key？"链接）
- 成功后自动进入 Step 3

**Step 3 — 就绪屏**
- 成功图标 + "一切就绪"
- 推荐操作卡片："试试对着麦克风说句话？"→ 主按钮跳转 `/live?tab=text`
- 次级链接"先看看其他功能"→ 跳转 `/dub`

### 5.2 实时翻译页（合并页）

**页面结构**：
```
┌──────────────────────────────────────────┐
│ page-header: "实时翻译"                    │
│ tab-bar: [文本模式] [耳机模式]              │
├──────────────────────────────────────────┤
│ config-bar (折叠态/展开态)                 │
├──────────────────────────────────────────┤
│ transcript-area (flex:1, scroll)         │
│   segment-card × N                       │
│   streaming-card (底部, 实时)              │
├──────────────────────────────────────────┤
│ control-dock (底部固定)                    │
└──────────────────────────────────────────┘
```

**Tab 切换**：shadcn Tabs 组件，切换时保留各自会话状态（两个 Tab 互不干扰，同一时间只有一个活跃会话）。

**配置栏**（config-bar）：
- 默认折叠为一行 chips：`[自动检测 → 英语]` `[语音: 关]` `[热词: 默认]`
- 点击展开面板：源语言 Select（含"自动检测"）、目标语言 Select（60 语种）、"同时生成语音" Switch（目标语言不支持音频时 disabled + tooltip 说明）、热词表 Select（双入口之一）
- 会话进行中配置栏锁定（灰显 + "会话进行中，配置已锁定"提示）

**段落卡片**（segment-card）：
- 默认态：只显示译文（Body-L），左侧 2px 状态线（streaming=琥珀脉冲 / done=透明 / interrupted=红）
- hover 态：浮现操作行——▶ 回放（有音频时）、原文展开箭头、时间戳
- 原文展开：Caption 字号 + text-secondary 色，含语言标签 + emotion badge
- 卡片间距 12px，无边框无阴影（靠间距和状态线区分），hover 时 surface 底色微亮

**底部控制坞**（control-dock）：
- 居中圆形主按钮（56px）：idle=主色"开始"麦克风图标 / recording=红色脉冲环"停止"
- 左侧：暂停/恢复按钮
- 右侧：重置按钮 + 性能徽章（"0.9s 响应" + 会话时长，Micro 字号）
- 录音中：顶部出现细进度指示（非进度条，是一条 2px 的呼吸线）

**耳机模式差异**：
- 进入耳机模式时，若未完成声道向导 → 强制触发 ChannelWizard（全屏 overlay）
- 运行时自动进入全屏字幕模式（见 §5.3）

### 5.3 全屏字幕模式（耳机模式运行时）

**视觉规格**：
- 背景：`#0A0A0C`，中心区域有呼吸光晕（径向渐变，主色 8% 不透明度，随音频播放缓慢缩放 1.0–1.05，周期 4s）
- 字幕区居中偏下（垂直 60% 位置）：
  - 原文：22px，`rgba(255,255,255,0.5)`
  - 译文：40px，`#FFFFFF`，font-weight 600
  - 段落间距 24px，只显示最新 2 段（当前段 + 上一段渐隐至 30%）
- 顶部控制条：半透明（`rgba(255,255,255,0.06)` 底 + backdrop-blur），高度 48px
  - 左：通道 badge（WS/WebRTC）+ 延迟数字
  - 中：无
  - 右：暂停按钮、结束按钮（红色 ghost）
- 退出：点击"结束"→ 淡出回正常页面，会话归档

### 5.4 文件配音工作台

**状态一：空态（未导入文件）**
- 中央拖放区：虚线圆角矩形（radius-xl），内含上传图标 + "拖入音频或视频文件" + 支持格式列表（Caption）
- 点击也可打开文件选择器

**状态二：预处理中**
- 文件名 + 时长信息卡
- 进度条（按 response.done 音频时间戳推进）+ 百分比 + "正在翻译…"
- 可取消按钮

**状态三：工作台（默认视图）**
```
┌────────────────────────────────────────────┐
│ toolbar: 文件名 · 时长 | [原声|配音] | 导出▾ │
├──────────────────────┬─────────────────────┤
│ source-panel         │ translation-panel   │
│  视频画面/波形        │  字幕卡片流          │
│  时间轴(可seek)       │  (跟随高亮当前段)    │
├──────────────────────┴─────────────────────┤
│ transport-bar: ▶ 大播放按钮 + 进度 + 时间    │
└────────────────────────────────────────────┘
```
- 左栏：视频则显示画面（16:9），纯音频则显示波形 canvas；下方时间轴
- 右栏：译文字幕卡片流，当前播放段高亮（primary-soft 底 + 左侧状态线）
- 底部：统一播放控制条
- "配音播放"：主操作按钮（主色），点击后右栏音频按漂移时间轴播放，左栏画面静音跟播

**第二层（渐进浮现）**：
- 段落卡片 hover：展开波形 + 单段重播按钮
- 时间轴：叠加漂移标记（琥珀色小三角，hover 显示漂移量 ms）
- 导出下拉：SRT（原文/译文）、配音 WAV、双语 TXT
- 高级设置入口（toolbar 齿轮）：音色选择（复刻 once/预设音色）、视觉增强开关、抽帧帧率

### 5.5 会议模式

**状态一：会前设置**
- 会议目标语言 Select（全场统一）
- 参会人名册编辑：列表式，每行 = 姓名输入 + 源语言 Select（含"自动检测"）+ 删除按钮；底部"+ 添加参会人"
- 头像自动分配：姓名首字 + 色块（从预设 8 色 palette 顺序分配）
- "开始会议"主按钮（≥2 人时可用）

**状态二：会议进行中**
```
┌──────────────────────────────────────────┐
│ speaker-ring (顶部区域, 水平居中)           │
│   [头像] [头像] [头像·热座发光] [头像] ...   │
├──────────────────────────────────────────┤
│ live-caption (当前发言实时字幕)             │
│   原文(Caption) + 译文(Body-L)             │
├──────────────────────────────────────────┤
│ timeline (历史发言卡片流, scroll)           │
│   turn-card: 发言人色块+名 | 原文 | 译文 | ▶│
├──────────────────────────────────────────┤
│ dock: [按下发言(大按钮)] [跳过播放] [结束]   │
└──────────────────────────────────────────┘
```
- 热座状态：发言人头像外圈 3px 主色环 + 呼吸动效（opacity 0.6–1.0, 2s 周期）
- "按下发言"按钮：idle 态为主色大按钮；他人 speaking/playing 时 disabled + 文案变"等待中…"
- 播放中：当前 turn-card 显示播放波形指示器；"跳过播放"按钮可用（主持人）
- 会议结束：生成会议摘要（时长、发言次数、参会人）→ 归档到历史

### 5.6 历史页

**结构**：
- 顶部：页面标题 + 筛选 chips（全部/实时/配音/会议）+ 搜索框
- 主体：按日期分组（"今天"/"昨天"/"7月27日"…），组标题 Caption 字号
- 会话摘要卡片：
  - 左侧：模式图标（圆形 soft 底色）
  - 中部：标题（自动生成，如"中→英 · 12分钟"或文件名）、时间、段落数
  - 右侧：平均延迟 badge + 展开箭头
  - 展开后：完整段落列表（原文/译文）、音频重播、导出按钮、"查看事件日志"链接、删除
- 空态：插画 + "还没有翻译记录" + 引导按钮"开始第一次翻译"

### 5.7 设置页

**四组分区卡片**（每组一张 surface 卡片，组标题 H2）：

1. **账户与连接**
   - API Key：脱敏显示 `sk-****...****` + "显示"/"编辑"按钮
   - Workspace Host：inline 编辑
   - 连接状态：绿点/红点 + "重新检测"按钮

2. **翻译偏好**
   - 默认语言对：双 Select（源/目标）
   - 默认音色：Select
   - 协议偏好：Radio（自动 / 强制 WebSocket）

3. **热词表**
   - 词表列表：名称 + 词条数 + 编辑/删除
   - "新建词表"按钮 → 内联编辑面板（名称 + 词条 textarea，一行一条"原文=译文"格式）

4. **高级**（默认折叠，标题旁标注"开发调试"）
   - 抽帧帧率 Select（1fps/2fps）
   - 完整音频负载日志 Switch
   - "打开日志目录"按钮

## 7. 动效规格

| 场景 | 动效 | 参数 |
|------|------|------|
| 新段落入场 | 上浮 + 淡入 | translateY(8px→0), opacity 0→1, 250ms ease-out |
| stash 完成 | 不透明度过渡 | 60%→100%, 150ms ease |
| 状态线 streaming | 呼吸脉冲 | opacity 0.5→1→0.5, 2s infinite |
| 页面切换 | 内容淡入 | opacity 0→1, 150ms ease-out |
| 热座头像 | 外圈呼吸 | opacity 0.6→1, 2s infinite |
| 字幕光晕 | 缓慢缩放 | scale 1→1.05, 4s ease-in-out infinite alternate |
| 播放指示器 | 三柱律动 | height 随机相位, 800ms infinite |
| 卡片展开 | 高度过渡 | grid-template-rows 0fr→1fr, 200ms ease |
| 侧边栏收缩 | 宽度过渡 | width 220→56, 200ms ease |
| 录音主按钮 | 外圈脉冲环 | scale 1→1.4 + fade, 1.5s infinite |

**禁止项**：页面级滑动转场、卡片弹跳入场、按钮 hover 缩放、无限旋转 loading（用 Skeleton 代替）。

## 8. 错误状态规格

| 错误类型 | 呈现方式 | 文案原则 |
|----------|----------|----------|
| 断线重连中 | 顶部 Toast 条（琥珀底）："连接中断，正在重连 (2/5)…" | 恢复后自动消失 |
| Key 失效 | 使用点原地 InlineAlert（红底 soft）+ "去设置页更新"按钮 | 不弹模态 |
| 麦克风权限拒绝 | 原地引导卡片 + 平台图文步骤（Win/macOS 各一套） | 步骤化，可操作 |
| 文件格式不支持 | DropZone 变为错误态 + 支持格式列表 + "换一个试试" | 明确告知支持什么 |
| 目标语言不支持音频 | Switch disabled + Tooltip 说明 | 预防式，不事后报错 |
| 未知错误 | InlineAlert + 可折叠"技术详情"（error code + 原始报文，可复制） | 一级人话，二级技术 |
